### What I learned

I learned how to properly center my elements in the viewport, how to deal with unpredictable padding and borders and how to properly format an image within a card. 

```css
body {
    background-color: hsl(212, 45%, 89%);
    font-family: Outfit;

    min-height: 100vh;
    display: flex;
    justify-content: center;
    align-items: center;
}
```
